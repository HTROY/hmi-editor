# 工程存储与跨设备同步

工程采用"本地优先 + 后端同步"的存储架构：编辑器把自动保存的全量快照写入浏览器 IndexedDB（刷新、页面切换后无感恢复），并在 io-backend 新增工程 API 提供显式的跨设备同步。后端用 SQLite `projects` 表存工程元数据、磁盘上每个工程存一份整包 `.hmi.zip`（manifest.json + assets/），上传/下载/导出都是同一压缩包，更新为整包原子替换；同步为显式动作，乐观锁用 `version` 校验，过期返回 409。`.hmi.json` 保留为旧格式兼容导入。选择本地优先是为了保证离线可编辑、刷新不丢状态，同时避免把后端变成编辑器的硬依赖。工程 API 需要完整鉴权，机制见 ADR-0004。
