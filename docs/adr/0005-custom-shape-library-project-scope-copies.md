# 工程级图元库与库项副本语义

编辑器需要支持用户自建可复用图元（组合选中图元或导入 SVG 入库），我们把图元库定为工程级数据：作为 `ProjectData.library` 顶层可选字段随自动保存、`.hmi.zip` 工程包和工程同步自动携带；库项是任意单个图元（含组）及其绑定/动画/事件的序列化定义；从图元库放置到页面时生成深拷贝副本，之后与库项不再关联，「重新同步」提供显式覆盖路径。选择工程级 + 副本语义是因为它与现有工程包/自动保存模型完全吻合，且避免引入实例引用与版本同步机制，让放置、撤销和逐实例编辑保持可预测；全局个人库或后端共享库可在后续作为独立层叠加，不改变本决策。

## Considered Options

- **链接实例（库项更新后所有实例联动）**：功能更强，但需要实例引用、库项版本和渲染解析机制，撤销/序列化复杂度明显上升，v1 不做；副本 + 显式「重新同步」覆盖了绝大多数场景。
- **全局个人库 / 后端共享库**：跨工程复用有价值，但涉及新的存储与权限范围，留作后续独立分支。
- **代码/插件式自定义渲染**：由 TS 类或 WASM 定义新图元类型，是另一条路线，与「组合入库」正交，不在本决策范围内。
