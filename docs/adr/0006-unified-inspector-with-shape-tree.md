# 检查器重构：右栏统一为图元树 + 编辑区，组内子图元仅在树中编辑

右栏从"11 个并列 Tab"重构为统一检查器（Inspector）：顶部常驻图元树（Shape Tree），按 z 序从最上层到最下层展示当前页全部图元，组可递归展开（默认折叠，展开状态按页面记忆在会话内存中）；下方是属性 / 绑定 / 动画垂直堆叠的可折叠编辑区。点表、连接、页面、报警、趋势、权限、脚本、报表等工程与管理面板移入左栏多 Tab 面板，与右栏形成"左侧工程数据、右侧当前图元"的分工；左右栏宽度均可拖拽调节并持久化到 localStorage。这样做的原因是为了满足"在图元树中看到全部图元、按层级选中、同一面板内编辑属性/绑定/动画"的核心诉求，同时让右栏职责单一，后续新增编辑能力不再挤占一个 Tab。

选择模型引入"选择路径"：组内子图元只能在图元树中选中并编辑属性/绑定/动画，画布点击仍以组为单位变换，画布对选中的子图元只画只读高亮框；子图元不允许删除，复制/粘贴仅支持顶层图元；子图元编辑的撤销按单次提交记录，历史命令携带父路径。图元树行提供可见/锁定开关、重命名、删除，以及同父范围内的拖拽换序（顶层图元之间、同一组内子图元之间；不支持跨组移动）；成组/取消成组经工具栏按钮与 Ctrl+G / Ctrl+Shift+G 触发，成组要求画布多选 ≥2 个顶层图元，取消成组一次只展开一层，两者都算一次撤销。树中选中图元不移动画布视图，多选（画布框选）时树只读高亮全部选中项，编辑区显示公共属性批量编辑。

选择"树选子图元 + 组级画布变换"是为了把组保持为画布交互的原子单位：命中测试、手柄变换、移动/缩放都不需要进入组内坐标，撤销历史也只需为子图元增加父路径寻址；画布直接编辑子图元可作为后续增强，不改变本决策。

Status: accepted

## Considered Options

- **保持 Tab 式右栏并新增图元树 Tab**：改动最小，但图元树会被埋进 11 个 Tab，编辑区与树分离，不符合"同一面板内选图元即编辑"的意图；用户选择完全重构。
- **画布直接点选并编辑组内子图元**：交互更直接，但需要组内坐标命中、子图元手柄变换与移动/缩放路径化，渲染与撤销改动面大；v1 只在树中编辑，画布保持组级原子变换。
- **树内多选**：与画布框选语义重叠，且批量编辑需要覆盖子图元寻址；v1 树内单选，画布多选在树上只读高亮。
- **允许删除/复制子图元**：删除会引入组内选中态与撤销寻址的边界问题，复制粘贴需要组坐标折算；v1 均不支持，子图元为"树选 + 编辑"。
